# 智聘科技 IT 服务手册

> 适用范围：智聘科技（ZhiMesh）全体员工。本手册条款与智聘 IT 服务台的校验规则保持一致（口径基准日 2026-09-13）；涉及具体工单、账号状态等数据的，以 IT 服务台实时查询结果为准。

## 第一章 总则

### 第1.1条 服务范围

IT 服务台为员工提供账号、VPN、邮箱、硬件、软件、网络六大类 IT 问题的统一支持。员工可通过 IT 服务台助手（数字员工）查询工单、账号状态与软件目录，并提交新工单。

## 第二章 账号与密码

### 第2.1条 账号体系口径

每位员工涉及三项独立 IT 状态：域账号、VPN、企业邮箱。三项状态分别管理、分别查询。

### 第2.2条 状态口径

三项状态的可取值如下：

| 项目 | 状态取值 |
| --- | --- |
| 域账号 | 正常 / 已禁用 |
| VPN | 正常 / 禁用 |
| 企业邮箱 | 正常 / 已注销 |

### 第2.3条 密码有效期

域账号密码按「密码过期剩余天数」管理，员工可随时查询本人密码剩余有效期。剩余天数在 7 天及以内时，系统判定为「即将过期」，请尽快修改密码。

## 第三章 工单类别

### 第3.1条 类别划分

工单统一分为六类：VPN、账号、硬件、软件、网络、邮箱。提交工单时须选择正确类别，类别须为以上六类之一。

## 第四章 紧急度判定

### 第4.1条 紧急度档位

工单紧急度分为三档：普通、紧急、危急。

### 第4.2条 判定标准

紧急度按故障影响面判定：

- 普通：个别员工无法正常工作；
- 紧急：部门级故障，一个部门及以上的员工无法正常工作；
- 危急：全公司级故障。

对紧急度判定有疑问的，可向 IT 服务台补充说明影响面。

## 第五章 工单状态与响应

### 第5.1条 工单状态

工单状态分为四种：待处理、处理中、已解决、已关闭。

### 第5.2条 新单受理

新提交的工单初始状态为「待处理」，由 IT 服务台在工作时间响应。

### 第5.3条 工单编号

每个工单有唯一编号，格式为 TK-YYYYMMDD-NNN（NNN 为系统自增序号，从 001 起）。查询工单进度请提供工单编号。

## 第六章 新建工单

### 第6.1条 所需信息

提交新工单须完整提供以下五项信息：

1. 工单标题（不能为空，简明描述问题）；
2. 问题类别（第3.1条六类之一）；
3. 紧急度（普通 / 紧急 / 危急）；
4. 问题描述（不能为空）；
5. 报告人姓名。

### 第6.2条 报告人资格

报告人须为账号表中登记的员工，且其域账号状态为「正常」；不在账号表中或域账号非正常状态的，不能作为报告人提交工单。

### 第6.3条 校验规则

工单提交按以下规则校验：标题与问题描述不能为空；类别须为六类之一；紧急度须为三档之一；报告人资格须满足第6.2条。

## 第七章 软件申请

### 第7.1条 可申请软件目录

办公软件须在可申请软件目录范围内申请，目录共 10 项，每项注明类别、是否需审批与说明。目录内软件分「免审批」与「需审批」两类。

### 第7.2条 免审批软件（6 项）

以下软件可免审批申请安装：

| 软件 | 类别 | 说明 |
| --- | --- | --- |
| VS Code | 开发工具 | 免费，轻量编辑器，可自行安装 |
| Postman | 开发工具 | 免费版即可满足接口调试，团队协作版需审批 |
| Docker Desktop | 开发工具 | 个人版免费，用于容器化开发环境 |
| WPS Office | 办公软件 | 企业版统一授权，全员可用 |
| 腾讯会议 | 办公协作 | 企业版统一部署，用于视频会议 |
| 企业微信 | 办公协作 | 全员标配，内部沟通与审批入口 |

### 第7.3条 需审批软件（4 项）

以下软件须审批后方可安装，审批口径如下：

| 软件 | 类别 | 说明（含审批要求） |
| --- | --- | --- |
| IntelliJ IDEA | 开发工具 | JetBrains 付费授权，后端/算法开发主力 IDE |
| Navicat | 数据库工具 | 付费授权，数据库连接管理，需 DBA 会签 |
| 向日葵 | 远程控制 | 远程控制软件，需信息安全审批后开放 |
| Adobe Photoshop | 设计工具 | 付费授权，仅设计岗，需部门负责人审批 |

## 附则

本手册自发布之日起施行，由 IT 部负责解释。遇到 IT 问题可先咨询 IT 服务台助手（数字员工）；具体工单进度与账号状态以 IT 服务台查询结果为准。
